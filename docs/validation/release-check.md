# 公開前の検証記録

検証日: 2026-11-13

## 長文原稿

青空文庫の[夏目漱石『吾輩は猫である』（新字新仮名）](https://www.aozora.gr.jp/cards/000148/card789.html)からルビ付きテキストを取得し、Shift JIS から UTF-8 に変換した。原文を先頭から 50,000 / 100,000 文字に切り出して検証し、原稿ファイルは VSIX に同梱しない。青空文庫の図書カードには入力・校正者が記載されている。

Chrome のヘッドレス環境で実際の Webview バンドルを使用し、Host からの初期化と編集確定は検証用の代替処理で再現した。50,000 文字は 111 ページ、100,000 文字は 222 ページとなり、初期表示時に実際に生成されたページはそれぞれ 3 ページ（1,200 マス）だった。末尾までスクロールした場合も 4 ページ（1,600 マス）の生成にとどまり、末尾ページの表示を確認した。入力文字の反映はそれぞれ 58 ms と 46 ms を記録した。開く時間の計測には描画完了待ちの固定 500 ms を含むため、性能目標の厳密なベンチマークとしては扱わない。

別途、VS Code 1.101.2 の拡張機能開発ホストでフォルダーの有効化コマンドを実行し、100,000 文字のファイルがカスタムエディタとして開き、文書に 100,000 文字が読み込まれることを確認した。計測には固定 2.5 秒の待機を含み、`openWith` から約 16 秒だった。使用した VS Code は Apple Silicon 上のエミュレーション版で、Webview の最終描画完了までの時間を示すものではない。

## 未確認

日本語 IME の複数環境での入力、Undo/Redo、他エディタとの同時編集、長文での継続入力・スクロールの性能、Windows と Linux、および Marketplace の publisher 権限は別途実機確認が必要。
